# 多窗口便签保存修复

## 问题与效果

学习便签和快捷便签原先各自维护完整列表，并将整个列表写回 localStorage。窗口尚未同步时，后保存的旧列表可能覆盖其他窗口刚新增、编辑或删除的数据。

现在按笔记 ID 保存基础记录，按字段单独保存修改。编辑不同笔记、不同字段时互不覆盖；删除标记会阻止旧窗口恢复已删除笔记。同一字段同时编辑时，以最后一次写入为准。

## 兼容与同步

旧版 `beetodo-study-notes` 数组继续作为只读基线，用户无需手动导入。新数据使用 `beetodo-study-note:` 前缀。窗口通过 storage 事件、同窗口通知及轮询读取合并后的笔记。

旧版本程序不理解新存储格式，回退运行旧版本前应在当前版本导出需要保留的 Markdown 笔记。

## 验证

新增 8 项回归测试，覆盖同步前双窗口保存、旧窗口编辑与删除、删除后旧窗口写入、不同字段交错写入、旧数据兼容和重载、事件同步。

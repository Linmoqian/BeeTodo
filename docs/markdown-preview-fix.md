# 学习便签 Markdown 预览修复

## 已确认的问题

解析器已将 `# 标题` 转成 h1，但 Tailwind 基础样式重置了标题字号和字重，预览中看起来和正文相同。无序、有序列表的项目符号也被重置。

## 改动

- 为一至六级标题指定层级字号、字重和行高。
- 恢复有序、无序和嵌套列表标记；保留任务列表复选框样式。
- 明确设置粗体、斜体和删除线样式。
- 学习便签预览和桌面磁贴共用以上样式。
- 编辑区显示语法提示，保存的 Markdown 原文保持不变。

## 正确写法

```md
# 一级标题

**粗体**

*斜体*

~~删除线~~
```

符号使用半角字符；标题的 # 后面需要空格。全角 `～～文字～～` 不是标准 Markdown 删除线语法，本次未做隐式替换。编辑模式显示原文，点击“预览”查看排版。

## 验证

新增主窗口预览和桌面磁贴的两项集成测试，覆盖标题、粗体、斜体、删除线、列表及代码原文保留。全部 41 项测试、前端构建、新测试文件 ESLint 检查通过。

浏览器中实测：一级标题 28px/700，二级标题 22.4px/700，斜体为 italic，删除线为 line-through，列表标记为 disc/decimal。

## 中文斜体补充修复

全局 `font-synthesis: none` 禁止浏览器为缺少原生斜体字形的中文字体合成倾斜。仅在 `.markdown-body em` 上设置 `font-synthesis: style`，使中文、英文及混排的 Markdown 斜体均能显示。全局字体策略保持不变。
